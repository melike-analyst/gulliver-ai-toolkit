# Game Data Analysis

When the user gives you a live-ops CSV or asks you to analyze game data:

1. Load the data.
2. Look at the numbers and describe what changed.
3. Point out anything that looks unusual.
4. Write a short summary for the user.

Keep it brief and easy to read.
